# Rakta Seva Connect

An Android application for connecting blood donors and recipients in real time.

## Features

- User Authentication
- Blood Donor Search
- Google Maps Integration
- Real-time Location Tracking
- Profile Management

## Tech Stack

- Kotlin
- Jetpack Compose
- Firebase
- Google Maps API

## Installation

```bash
git clone https://github.com/Sushant-Pasarge/Rakta-Seva Connect1.git
```

Open in Android Studio and run the project.
